## v1.2.0 — 관심 편집 시트, 디자인 시스템 통합, 라이트/다크 호환 강화

### 관심 편집 시트

- **EditSymbolsSheet** — 종목 우클릭 → 편집을 누르면 풀스크린 편집 시트 진입. 그룹 가로 탭으로 다른 그룹 즉시 전환
- **카테고리 섹션** — 국내주식 / 해외주식 / 지수·선물 자동 분류. 메인 뷰와 동일한 순서로 표시
- **다중 선택 + 일괄 액션** — 체크박스로 여러 종목 선택 후 한 번에 삭제 / 다른 그룹으로 이동
- **세로 드래그 순서 변경** — 섹션 내에서 종목 순서 변경. 가로 드래그는 차단해 시트 안 가로 스크롤 사고 방지
- **빈 그룹 안내** — 친근한 안내 메시지 + 종목 추가 가이드

### 그룹 편집 바텀시트

- **GroupEditSheet** — 편집 시트 상단 "그룹편집" 탭에서 진입. 그룹 자체 관리 전용
- **추가 / 삭제 / 이름 변경 / 순서 변경** — 한 시트에서 모두 가능
- **마지막 그룹 보호** — 그룹이 하나뿐이면 삭제 버튼 비활성
- **동일 이름 차단** — 이미 있는 그룹 이름으로 생성/변경 시도 시 빨강 테두리 + "이미 있는 그룹 이름이에요" 안내
- **추천 뱃지** — 그룹 이름 변경 모달에도 국내/해외/배당주/성장주 등 추천 칩 표시

### 그룹 이동 picker

- **GroupPickerSheet** — 편집 시트에서 종목 이동 시 어떤 그룹으로 갈지 선택
- **모든 그룹 표시** — 현재 그룹은 흐리게 + "현재 그룹" 라벨로 시각화. 새 그룹 추가도 picker 안에서 가능
- **닫기 / 확인 2-button CTA** — 그룹 선택 시에만 확인 활성화
- **이동 직후 타겟 그룹 전환** — 이동 완료 시 편집 시트의 활성 탭이 자동으로 타겟 그룹으로 이동

### 메인 뷰 정리

- **DnD 완전 제거** — 메인 화면 종목 로고 hover 시 나오던 드래그 핸들(≡) 제거. 편집은 편집 시트에서만 가능
- **우클릭 메뉴 간소화** — 상세 정보 보기 + 편집 두 항목으로 통일 (이전: 다른 그룹으로 이동 / 삭제 인라인)
- **시장 시간 정렬 일관성** — 리스트 / 그리드 / 타일 모든 뷰에 `sortByMarketOpen` 적용. 해외만 개장 중이면 해외 → 국내 → 지수·선물 순으로 자동 전환
- **전체 탭 내부 정렬 일관성** — 전체 탭에서 프리셋 그룹 내부도 동일한 카테고리 순서로 자동 정렬

### 디자인 시스템 통합

- **ListHeader 컴포넌트** — 페이지/섹션 헤더 단일화. 메인 그룹 헤더, 편집 시트 섹션, 설정 캡션, 투자정보 섹션 모두 한 컴포넌트로
- **CheckCircle 컴포넌트** — 다중 선택 원형 체크 인디케이터. 편집 시트 / 그룹 picker 공통 사용. 두꺼운 stroke로 가독성 강화
- **sheetActionBtnStyle 유틸** — 시트 푸터 CTA 버튼 표준 (primary / danger / neutral 3-variant)
- **restrictToYAxis modifier** — DnD 세로축 고정. 시트 안 가로 스크롤 무한 증식 사고 방지
- **groupTabStyle.tabPrimary** — 전체 / 그룹편집 같은 액션 탭은 outline 강조로 일반 그룹 탭과 위계 차별화
- **좌우 패딩 그리드 통일** — TitleBar / MarqueeTicker / PresetTabs / ListHeader / StockRow / StockGrid / StockTile / StatusBar 전 영역 좌우 `spacing.xl`(16px)로 정렬

### 라이트/다크 호환

- **라이트모드 hover 사라짐 사고 수정** — neutral 버튼이 라이트에서 `filter: brightness(1.08)` + bg.elevated 조합으로 흰 배경에 묻혀 사라지던 버그. 명시적 `primarySoft` hover bg로 변경
- **Menu 라이트모드 글자 두께 보정** — 라이트에서 메뉴 항목이 얇아 보이던 문제. 라이트는 medium / 다크는 regular로 자동 분기
- **다크 토스트 / 모달 톤 정돈** — 라이트와 다크에서 모두 동일 위계로 시각 확인

### 시트 시스템 강화

- **BottomSheet 닫힘 애니메이션** — 휙 사라지지 않고 슬라이드 다운 + 오버레이 페이드 아웃 200ms
- **시트 행 풀-블리드 hover** — `width: calc(100% + 32px); margin-left: -16px;` 패턴으로 시트 좌우 끝까지 hover 배경 채움
- **BottomSheet body overflow-x: hidden** — 풀-블리드 hover 시 가로 스크롤바 생성 방지

### 버그 픽스

- **메뉴 외부 클릭 닫힘** — SheetLayout이 `onMouseDown`까지 `stopPropagation`하면서 useOutsideClick이 깨지던 사고. click/contextmenu만 차단하도록 수정
- **그룹 이름 변경 후 메인 복귀** — inline `onClose` 콜백이 매 렌더 새 ref가 되어 `useBackAction` 스택이 reshuffle되던 사고. 모든 시트/모달/메뉴 콜백 `useCallback`으로 안정 참조 표준화
- **전체 탭 우클릭 편집 시 첫 그룹 열림** — 종목 실제 소속 그룹을 우선 매칭하도록 수정
- **편집 시트 카테고리 순서와 메인 뷰 불일치** — 둘 다 동일한 섹션 분할 로직 사용
- **그룹 이동 후 메인으로 복귀하던 사고** — 이동 후 편집 시트는 그대로 두고 picker만 닫음
- **그룹 이동 바텀시트 딤 클릭 시 종목 웹뷰 동시 오픈** — 부모 행 onClick 발화 차단
- **새 그룹 추가 시 메인 활성 그룹 전환** — 편집 시트 안 그룹 추가는 `activate: false`로 메인 영향 X
- **정렬 강제 'custom' 전환 시 토스트 안내** — 사용자가 name/change 정렬 사용 중인데 편집 시트에서 reorder하면 자동으로 custom 전환 + 메인 복귀 시 안내 토스트

### 지수 / 시장지표

- **지수 웹뷰 URL 통일** — 종목으로 추가한 지수와 시장지표의 지수가 같은 URL로 열림 (`/domestic/index/{code}`, `/worldstock/index/{ref}` — `/price` suffix 제거)
- **투자정보 증시현황 요약 강조** — 상승/보합/하락 카운트를 라벨(`fontSize.sm`) + 큰 숫자(`fontSize.xl`, extrabold, 색상) 분리해서 시각 위계 강화
- **투자정보 지수 라벨 ListHeader 통합** — 시트 안 다른 섹션 헤더와 일관성

### 메인 화면 미세 조정

- **상단 nav 좌우 여백** — `spacing.md` → `spacing.xl` 그리드 정렬
- **푸터 종목 검색 툴팁** — "종목 추가" 툴팁 추가
- **MarqueeTicker ↔ PresetTabs 간격** — PresetTabs 상단 `spacing.sm` 마진 보정
- **설정 화면 섹션 간 간격** — 그룹 간 `spacing.lg` 마진 확보

### 성능

- **EditRow memo** — 선택 토글 시 변경된 행만 리렌더
- **SortableContext items 안정 참조** — `sections.itemIds` / `presetIds` useMemo로 매 렌더 새 배열 생성 방지

### 내부

- 새 모달 / 시트 / 메뉴 콜백은 `useCallback` 안정 참조 표준화 (`useBackAction` 스택 reshuffle 방지)
- 토큰 외 raw px / hex / rgba 사용 0건 (헌법 강제)
- 프로젝트 헌법 v2 + 4-agent 팀 (Orchestrator / Architect / Designer / Reviewer) 도입 — 일관성 자동 감사 체제

- 메인 뷰 DnD 의존성 제거 → 번들 사이즈 소폭 감소
