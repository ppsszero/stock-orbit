# v1.2.0 — 관심 편집 시트 + 디자인 시스템 통합

## ✨ 새로운 기능

### 관심 종목 편집 시트 (`EditSymbolsSheet`)
종목 우클릭 → 편집을 누르면 풀스크린 편집 시트가 열려요.
- 그룹 가로 탭으로 다른 그룹으로 즉시 전환
- 국내주식 / 해외주식 / 지수·선물 카테고리별 섹션 표시
- 드래그로 종목 순서 변경 (세로축 고정)
- 다중 선택 후 일괄 삭제 / 다른 그룹으로 이동
- 빈 그룹은 친절한 안내 메시지

### 그룹 편집 바텀시트 (`GroupEditSheet`)
편집 시트 상단의 "그룹편집" 탭을 누르면 그룹 자체를 관리해요.
- 그룹 추가 / 삭제 / 이름 변경 / 순서 변경
- 마지막 그룹은 삭제 보호
- 동일 이름 그룹 생성 차단 + 시각 피드백

### 그룹 이동 picker (`GroupPickerSheet`)
편집 시트에서 종목을 이동할 때 어떤 그룹으로 갈지 선택해요.
- 모든 그룹 보여주고 현재 그룹은 흐리게 표시
- 닫기 / 확인 2-버튼 CTA
- 새 그룹 추가도 picker 안에서 가능
- 이동 완료 시 편집 시트가 자동으로 타겟 그룹 탭으로 전환

### 시장 시간 정렬 일관성
- 모든 뷰모드(리스트 / 그리드 / 타일)에 `sortByMarketOpen` 적용
- 해외만 개장 중일 때 해외 → 국내 → 지수·선물 순으로 자동 정렬
- 전체 탭 안 프리셋 그룹 내부도 동일한 카테고리 순서 일관성

### 지수 웹뷰 URL 통일
- 종목으로 추가한 지수와 시장지표의 지수가 같은 URL로 열려요 (`/domestic/index/{code}`, `/worldstock/index/{ref}` — `/price` suffix 제거)

## 🎨 디자인 시스템 정비

### 새 공통 컴포넌트
- **`<ListHeader>`** — 페이지/섹션 헤더 통합. 메인 그룹 헤더 / 편집 시트 섹션 / 설정 캡션 / 투자정보 모두 한 컴포넌트로
- **`<CheckCircle>`** — 다중 선택 원형 체크 인디케이터. 편집 시트 / 그룹 picker 공통

### 새 공통 유틸
- **`sheetActionBtnStyle('primary' | 'danger' | 'neutral')`** — 시트 푸터/CTA 버튼 표준
- **`restrictToYAxis`** modifier — DnD 세로축 고정 (가로 스크롤 무한 증식 방지)
- **`groupTabStyle.tabPrimary`** — 전체 / 그룹편집 같은 액션 탭의 outline 강조

### 좌우 여백 그리드 통일
TitleBar / MarqueeTicker / PresetTabs / ListHeader / StockRow / StockGrid / StockTile / StatusBar 전 영역 좌우 `spacing.xl` (16px) 그리드로 정렬해서 들쭉날쭉하던 시각 일관성 확보.

### 메인 뷰 DnD 제거
편집은 편집 시트에서만 가능. 메인 화면 종목 로고 hover 시 나오던 드래그 핸들 (≡) 사라져서 시각 깔끔.

## 🐛 버그 픽스

- 메뉴 외부 클릭으로 닫힘 — SheetLayout이 `onMouseDown`까지 stopPropagation 하면서 useOutsideClick 깨졌던 사고 수정
- 그룹 이름 변경 후 메인으로 빠지던 사고 수정 — inline `onClose` 콜백이 매 렌더 새 ref되어 `useBackAction` 스택을 reshuffle했음. `useCallback`으로 안정 참조
- 우클릭 편집 시 전체 탭에서도 종목 실제 그룹이 열리도록 수정 (이전엔 첫 번째 그룹으로 떨어짐)
- 라이트모드 "완료" 버튼 호버 시 흰색 배경에 묻혀 사라지던 사고 수정 — `filter: brightness` 대신 명시적 `primarySoft` 호버 배경
- 가로 DnD 시 좁은 시트 안에서 가로 스크롤 무한 증식하던 사고 수정 — `restrictToYAxis` modifier + body `overflow-x: hidden`
- 편집 시트의 종목 카테고리 순서가 메인 뷰 표시 순서와 달랐던 일관성 깨짐 수정 — 둘 다 동일한 섹션 분할 로직
- 그룹 이동 바텀시트 딤 클릭 시 부모 종목 행의 onClick까지 발화해 웹뷰가 함께 열리던 사고 수정
- 정렬 강제 `'custom'` 전환 시 메인 복귀 토스트 안내 추가

## 🚀 성능

- `EditRow` 컴포넌트 `memo` — 선택 토글 시 변경된 행만 리렌더
- `SortableContext items` 안정 참조 (`sections.itemIds`, `presetIds` useMemo)
- BottomSheet 닫힘 시 슬라이드 다운 + 오버레이 페이드 아웃 애니메이션
