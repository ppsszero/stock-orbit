## v1.2.9 — 데이마켓 실시간가 끊김 자동 복구

### 버그 수정 (크리티컬)
- 데이마켓(미국 오버나잇) 가격이 받아지다가 알 수 없이 '장마감'으로 굳고, 이후 앱을 재실행하기 전까지 영영 갱신되지 않던 문제 수정
- 원인: 네트워크가 끊김 이벤트 없이 조용히 죽는 경우(절전/최대절전 깨어남, WiFi 전환, VPN 재접속 등) 야후 실시간 연결이 살아있다고 착각 → 데이터가 멈춘 채 5분 뒤 '장마감'으로 표시되고 재연결이 시도되지 않음

### 개선
- 연결 상태 감시(watchdog) 추가 — 90초간 응답이 없으면 죽은 연결로 판단하고 자동 재연결 (영구 먹통 → 최대 90초 내 복구)
- 절전에서 깨어나면 즉시 재연결 — 데이마켓 가격이 바로 다시 흐름
