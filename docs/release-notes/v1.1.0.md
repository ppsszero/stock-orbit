## v1.1.0 — Tabs 컴포넌트 신설, 라이트모드 위계 보정, 시트 레이아웃 일관화

### 새로운 탭 시스템
- 시트 내 페이지 전환을 신설 Tabs 컴포넌트로 통합 (뉴스 / 투자정보 / 글로벌 실시간 랭킹 / 종목검색 / 시스템 로그)
- 메인 탭(underline)과 서브 탭(pill) 2단 위계 도입 — 정보 계층이 직관적으로 드러남
- 탭 전환 시 부드러운 슬라이딩 인디케이터 + 미세한 클릭 펄스 인터랙션
- 아이템이 많아지면 가로 스크롤(fluid), 정렬 옵션(left/center/between) 등 유연한 옵션 제공
- 컨테이너 리사이즈·폰트 로드에도 인디케이터 자동 재배치

### 라이트모드 위계 보정
- 흰 페이지 위에서 카드 면이 안 보이던 문제 해소 — cardBg를 살짝 회색으로 정돈
- 코스피/코스닥 등 서브 탭과 카드 면이 같은 톤이라 위계가 죽던 문제 해소
- 헤더/푸터 영역을 본문보다 명확히 다운된 sunken 톤으로 분리

### 시트 레이아웃 일관화
- nav 아래 가로선 중복 문제 정리 — 탭 underline이 구분선 역할 대체
- 검색 시트도 다른 시트와 동일하게 공용 레이아웃 사용 (자체 구현 제거)
- 글로벌 실시간 랭킹·종목 검색 — 메인 탭을 맨 위로, 관심종목 그룹 선택을 푸터로 재배치
- 시트 nav 아래 가로선 한 단계 약화

### 카드형 정보 표시
- 투자정보 매매동향 / 프로그램매매 / 등락종목 — outline 박스에서 한 덩어리 회색 면 카드로
- 금리 시트 — 컬럼 테이블에서 row 단위 개별 카드로 (깃발 hero + 큰 금리값 + 다음 발표일 강조)
- 데이터 로딩 중에도 자리는 미리 잡고 값을 0으로 표시 — 위치 점프 없음

### 새로운 컴포넌트
- NumberStepper — 숫자 입력기 (설정의 스크롤 속도 등). −/+ 버튼 + 직접 입력 + 휠 스크롤 지원
- 빈 입력 후 포커스 이탈 시 기본값으로 자동 복귀, 페이지 스크롤과 휠 충돌 방지
- 사이즈 sm/md/lg, 비활성, 접근성(aria-label, aria-live) 지원

### 로더 통합
- 페이지/시트 로딩 인디케이터 모던 ring spinner로 통합 (파란 호 + 옅은 베이스 ring)
- 라벨 텍스트 옵션 추가 — "페이지를 불러오는 중..." 등 상황별 안내
- 종목 상세 / 웹뷰 / 검색 / 금리 등 흩어져있던 인라인 스피너 일괄 교체
- `fill` 옵션 — 부모 flex 영역 전체 차지하며 중앙 정렬 (랭킹/뉴스/검색/금리 시트 적용 — 푸터가 끌려오던 문제 해소)
- 타일뷰 강력 새로고침 직후 1×1 회색 타일 무더기 가림 — prices 데이터 준비될 때까지 로더로 대체

### 검색 개선
- 검색 결과 행에 외부 링크 버튼 추가 — 네이버 증권 페이지를 시트 내 웹뷰로 열기
- 검색어 X 버튼 클릭 시 입력란 자동 포커스 — 연속 검색 흐름 매끄럽게
- 결과 없을 때 안내 문구 줄바꿈 정리

### 시스템 로그 가독성
- API 로그 메시지를 "Fetch" 일괄 표기 대신 의미별로 변환 — "국내 지수 폴링 — 3개" 식
- 로그 row hover/active 색상을 다른 행들과 동일한 accent tint(11% / 14%)로 통일
- 좌측 padding 축소 — 레벨 뱃지가 시트 좌측 끝과 정렬

### 웹뷰 안정화 + 인터랙션 강화
- 종목 상세 / 시장지표 / 채권·금리 진입 시 검은 화면 멈춤 현상 해소 — 고정 시간(150ms) 대기 대신 dom-ready 이벤트 기반으로 표시
- 모바일 페이지의 가로 carousel(탭 strip 등)을 마우스 드래그로 스크롤 가능 — webview에 drag-to-scroll JS 주입
- WebView nav에 보조 정보(subtitle) 추가 — 종목 상세는 종목명, 시장지표/금리는 분류명을 우측에 표시

### 시장지표 시트 개편
- 카테고리(주요 지수 / 환율 / 에너지 / 금속)를 underline 탭으로 분리 — 한 화면 집중, 스크롤 부담 ↓
- row 클릭 시 네이버 모바일 페이지 웹뷰로 열기
- 현재가 색상을 등락 방향(빨강/파랑/회색)으로 반영, 폰트 사이즈 ↑
- row 사이 미세한 점선(dotted) 구분 + 양옆 여백 + hover tint
- 갱신 중에도 사용자가 보던 탭 유지

### 채권·금리 시트 확장
- "금리" → **"채권·금리"** 로 이름 변경
- **국채수익률** 탭 신설 — 미국/한국/일본/독일/중국 국채 10년 수익률
- 서브 탭 3개: 국채수익률 / 기준금리 / 국내금리
- row 클릭 시 네이버 모바일 페이지 웹뷰로 열기 — 좌측 항목명, 우측 분류명
- 카드 면 제거 → 미세 점선 구분 + 양옆 여백
- 현재가 색상을 등락 방향으로 반영, 호버 tint

### 기타
- 그리드 카드 외곽 border 제거 — 면색만으로 카드 분리
- `feedback.flat` 색 한 톤 업 (라이트 #6B7684→#4E5968, 다크 #6B7684→#B0B8C1) — 등락 0% 케이스 가독성 ↑

### UI 디테일
- 토글 스위치 — ON/OFF 시 흰 원 크기가 다르게 변형 (켜진 상태가 살짝 더 큼)
- 국가 뱃지 hue 재분배 — KR 파랑 / US 오렌지 / JP 청록 / CN 마젠타 / HK 보라 / UK 그린 / VN 노랑
- 등락률 0% 표기 — `─ 0.00%` 회색 대시 제거, 회색 텍스트로 단순화
- 글로벌 실시간 랭킹·뉴스·검색·로그 — 행 사이 가로선 제거, 마우스 오버는 미세한 푸른 tint로 통일
- 툴팁 표시 속도 절반으로 단축 (400 → 200ms)
- 경제 캘린더 날짜 네비 — 외곽 보더 제거, 면 처리. "오늘" 버튼은 accent tint 강조
- 상단 투명도 슬라이더 thumb 외곽 보더 제거 — 깔끔한 원형
- 스크롤바 톤 — 다크는 더 약하게(14.5%), 라이트는 더 또렷하게(37.5%)로 모드별 보정
- 웹뷰 nav 타이틀 — 다른 시트와 vertical baseline 통일

### 내부 정리
- 컬러 토큰 정비 — 라이트/다크 cardBg, bgSecondary 톤 재배치, accent 11% alpha(`accentSoft`) 토큰 신설
- 컴포넌트 의미 분리 — SegmentedControl(옵션 선택) vs Tabs(페이지 전환) 역할 명확히
- 데이터 일관성 — 표시 문자열 역추론 대신 transform 단계에서 방향 정보 부여
- 빠른 탭 전환 시 race condition 차단 — stale flag로 늦은 응답 무시
- 2단 탭 padding 패턴 공통 추출 (`subTabPadStyle`)
- 인라인 매직넘버 → 토큰 (`fontSize.xl/xs`, `radius['2xl']` 등)
- 라이트 halation 보정 — font-smoothing 방향 정정 + text-shadow trick (1.0.10에서 도입한 부분 다듬음)
- Tabs 클릭 애니메이션 안정화 — ResizeObserver를 마운트 시 1회만 생성해 `gsap.to`와 타이밍 충돌 제거
- `DEFAULT_SETTINGS` export — NumberStepper 빈 입력 fallback이 store의 단일 진실 소스 참조
