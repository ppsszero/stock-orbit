## v1.1.0 — 증시현황 트리맵, 뉴스/리서치 재편, 시트 시스템 대대적 정비

### 🆕 새 메뉴

- **투자정보 → 증시현황** 신설 — 시총·등락률 기반 **트리맵**으로 국내/미국 섹터 한눈에 파악. 섹터 클릭 → 바텀시트로 대표 종목 표시 → "업종 보러가기"로 네이버 모바일 페이지 진입
- **뉴스 → 뉴스/리서치 메인탭 분리** — 뉴스 4종(실시간 속보 / 주요 뉴스 / 많이 본 뉴스 / 해외뉴스) + 리서치 6종(데일리 / 국내종목 / 산업 / 투자 / 경제 / 채권). 각 카테고리 끝에 "더보기" 외부 웹뷰
- **해외뉴스 종목 칩** — 기사 제목 위에 연관 종목 칩(등락률 색상). 칩 클릭 시 해당 종목 페이지로 바로 진입
- **시장지표 시트 통합** — 기존 마퀴 시트가 "시장지표"로 이름 변경. 4 카테고리: 주요 지수 / 환율 / 채권·금리 / 원자재(에너지·금속·농축산물·운송 4종)
- **검색 상위 랭킹** — 글로벌 실시간 랭킹에 거래량·거래대금에 이어 "검색 상위" 탭 추가 (국내 전용)

### 🎨 시트 시스템 정비

- **Tabs 컴포넌트** — 시트 내 페이지/카테고리 전환을 일관된 underline/pill 탭으로 통합. GSAP 슬라이딩 indicator, 클릭 펄스, 가로 drag/휠 스크롤, 활성 탭 자동 가시화
- **BottomSheet** — 섹터 상세 등에서 사용. 핸들 잡고 끌어 닫기, 딤 클릭/ESC 닫기, 80px 스레숄드
- **Modal 통합** — 종목 상세 모달, 그룹 추가/이름변경, 전체 초기화 확인 모달 모두 공통 Modal로 마이그레이션. X 버튼 제거 + 하단 "확인" CTA로 일관
- **종목 상세 모달** — X 닫기 → 풀폭 "확인" CTA. 좌측 종목명 / 우측 종목코드. 분리선 양옆 inset
- **시트 풀폭 hover** — 시장지표·채권금리 row의 hover 배경이 좌우 끝까지 풀로. dotted divider만 양옆 inset

### 🔄 새로고침 시스템 통합

- **1회 누르면 시트 전체 갱신** — 어느 탭에 있든 시트 데이터 일괄 force fetch. 탭마다 따로 누를 필요 없음
- **마지막 갱신 시각** — 새로고침 버튼 hover 시 "5분 전 갱신" Tooltip
- **30초 cooldown** — 연속 클릭 차단. dim 처리 + 클릭 시 "N초 뒤에 다시 시도해주세요" 토스트
- **토스트 받침 처리** — "주요 뉴스를 / 산업분석을" 한국어 조사 자동 (을/를)

### 🌐 웹뷰 안정화

- **검은 화면 멈춤 해소** — 고정 150ms 대기 → dom-ready 이벤트 기반 + 3초 fallback + 10초 timeout
- **drag-to-scroll** — 모바일 페이지 가로 carousel/탭 strip을 마우스 드래그로 조작. 텍스트 영역은 선택 차단해 충돌 없음
- **마우스 4/5 버튼** → 브라우저 히스토리 back/forward
- **웹뷰 포커스 단축키 forward** — webview에 포커스 가있어도 F9 스크린샷 등 앱 단축키 정상 동작

### 🎯 카드형 정보 표시

- **투자정보 매매동향** — outline 박스 → 한 덩어리 회색 면 카드 (개인·외국인·기관 / 차익·비차익·전체 / 상승·보합·하락)
- **채권·금리** — 컬럼 테이블 → row 단위 카드 (깃발 hero + 큰 금리값 + 다음 발표일 강조). 국채수익률·기준금리·국내금리 3 서브탭

### 🔍 검색·로그·뉴스 잔손질

- 검색 결과 외부 링크 버튼 + X 클릭 시 input 자동 포커스
- 시스템 로그 메시지 의미별 ("Fetch" → "국내 거래량 상위" 등) + 좌측 패딩 조정
- 모든 리스트(랭킹·뉴스·검색·로그) 행 사이 가로선 제거. accent tint hover로 통일

### 🎨 라이트모드·디테일

- 라이트모드 카드면 visibility 향상 (cardBg 톤 정돈), halation 보정
- 글자 두께 라이트/다크 자동 보정 (font-smoothing + text-shadow trick)
- 다크/라이트 스크롤바 톤 모드별 최적화
- 토글 스위치 ON/OFF 흰 원 크기 차이
- 국가 뱃지 hue 재분배 (KR 파랑 / US 오렌지 / JP 청록 / CN 마젠타 / HK 보라 / UK 그린 / VN 노랑)
- 툴팁 표시 중 스크롤 시 즉시 숨김 (앵커 어긋남 방지)
- 그리드 카드 외곽 border 제거

### ⚙️ 새로운 컴포넌트

- **NumberStepper** — 설정의 스크롤 속도 등 숫자 입력. −/+ 버튼 + 직접 입력 + 휠 스크롤 + 빈 입력 fallback
- **LoadingCenter** — 페이지/시트 로딩 인디케이터 통합 (ring spinner). 기존 인라인 스피너 일괄 교체
