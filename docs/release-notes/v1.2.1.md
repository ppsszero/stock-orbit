## v1.2.1 — 라이트모드 가독성 / 트레이 업데이트 모달 수정

### 라이트모드 가독성

- **증시현황 섹터 트리맵 flat 타일 글자 안 보임 수정** — 변동률이 0인 섹터(예: "은행 +0.00%")가 라이트모드에서 거의 흰색 배경 위에 흰 글자라 안 보이던 사고. StockTile flat 처리 패턴과 동일하게 텍스트 색 dark로 override

### 트레이 업데이트 모달

- **모든 화면에서 업데이트 모달 표시** — 트레이 우클릭 → 업데이트 확인 누르면 설정/검색/랭킹/투자정보 등 어떤 시트가 열려있어도 모달이 위에 정상 표시 (기존 z-index 100으로 시트 뒤에 깔리던 버그 수정)
- **X 버튼 제거 + 하단 CTA 일관** — Modal 컴포넌트로 통합. phase별 적절한 액션 버튼:
  - 준비 완료: "나중에" / "지금 재시작" (2-button)
  - 최신 버전: "확인"
  - 실패: "닫기"
  - 다운로드 중: "백그라운드로"
- **확인 버튼 풀너비 복원** — Modal.Actions가 stretch되지 않아 버튼이 줄어들던 사고 수정

### 내부

- UpdateBanner 자체 backdrop/card 폐기, 공통 `<Modal>` compound로 마이그레이션 (헌법 3 위반 해소)
- raw `z-index: 100`, `border-radius: 14px` 등 토큰 외 raw 값 제거
