## v1.2.7 — 데이마켓 종목 페이지 선택

### 데이마켓, 어디서 볼지 고를 수 있어요
- 데이마켓(주간거래) 중인 미국 종목을 클릭하면 네이버/야후 중 어디서 열지 물어봐요. 네이버는 데이마켓 시세를 보여주지 않아서, 야후를 고르면 데이마켓 가격 흐름까지 그대로 볼 수 있어요.
- "선택 기억하기"를 체크하면 다음부터 묻지 않고 바로 열려요. 설정 > 데이터 > "데이마켓 종목 페이지"에서 언제든 바꿀 수 있어요.
- 데이마켓이 아닌 시간대(정규장·프리·애프터·장마감)는 지금처럼 항상 네이버로 열려요.

### 종목 페이지가 가벼워졌어요
- 종목 페이지(웹뷰)에서 광고·트래커 요청을 차단해요. 광고 무게 때문에 느렸던 야후 페이지가 한층 빠르게 떠요. 브라우저의 광고차단 확장과 같은 역할을 앱이 대신해요.

### 내부 정리
- 리스트뷰 종목코드와 세션 라벨이 미세하게 어긋나 보이던 문제 보정 (소수 line-height의 브라우저 반올림 이슈)
- 상태 닷(●) 광학 위치 보정 — 리스트/그리드 공통
- 웹뷰 소스 결정 로직을 순수 함수로 분리하고 unit test 추가
