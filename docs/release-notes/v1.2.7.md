## v1.2.7 — 데이마켓 종목 페이지 선택 / 웹뷰 광고 차단

### 데이마켓
- 데이마켓 중 미국 종목 클릭 시 네이버/야후 선택 모달 — 야후는 데이마켓 시세 확인 가능
- '선택 기억하기' 체크 시 다음부터 묻지 않고 바로 열림 — 설정 > 데이터 > '데이마켓 종목 페이지'에서 변경
- 데이마켓 외 시간대(정규/프리/애프터/장마감)는 기존대로 네이버

### 웹뷰
- 종목 페이지 광고·트래커 차단 — 광고 무게로 느리던 야후 페이지 로드 속도 개선

### 기타
- 리스트뷰 종목코드/세션 라벨 미세 세로 어긋남 보정
- 세션 상태 닷 광학 위치 보정 (리스트/그리드 공통)
